# Configs

Configuration files for planned experiments.

- `benchmark_manifest.yaml`: Canonical staged EPANET benchmark manifest (small/medium/large) and source policy.
- `split_manifest_plan_a.yaml`: Plan A benchmark partitioning (train/validation/test benchmark ids).
- `split_manifest_plan_b.yaml`: Plan B compact benchmark partitioning.
- `plan_a.yaml`: Main study (physics-aware generative augmentation).
- `plan_b.yaml`: Reduced fallback study (plain augmentation + detector baseline).

These files are intentionally simple and can be expanded as implementation grows.
